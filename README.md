# My First C++ Projects

Hello! My name is Fatima, and I am a Computer Science student.

This repository contains my first C++ projects, created to practice basic programming concepts.

## Projects

### 1. Character Classifier
Identifies whether an entered character is an uppercase letter, lowercase letter, digit, or special symbol.

### 2. Temperature Converter
Converts temperature from Celsius to Fahrenheit.

### 3. Student Grade Calculator
Calculates a student's grade based on a mark out of 100.

### 4. Equation Calculator
Calculates the value of y using the equation:

`y = x * x + 5 * x - 3`
